# Mova Studio

Studio IA gratuit dans le navigateur :
- **Vidéo IA** : texte → vidéo et image → vidéo, avec 12 mouvements de caméra (dolly, orbite, crash zoom, drone FPV, bullet time…). Moteurs gratuits hébergés sur Hugging Face (LTX-2.3, LTX Video, Wan 2.2).
- **Image IA** via Pollinations (gratuit, sans compte), avec envoi direct vers la vidéo IA.
- **Effets caméra** : animation instantanée et illimitée d'une image, export MP4/WebM dans le navigateur.
- Galerie locale, et token Hugging Face optionnel pour un quota plus grand.

Site 100 % statique (GitHub Pages).
