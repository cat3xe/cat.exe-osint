# Mova Studio

Studio IA gratuit dans le navigateur :
- **Génération d'images IA** (via Pollinations, gratuit, sans compte ni clé API)
- **12 mouvements de caméra** cinéma : zoom, travelling, tilt, crash zoom, orbite, spirale, caméra épaule, révélation, whip pan…
- **Export vidéo** MP4/WebM directement dans le navigateur (720p / 1080p, 2 à 10 s)
- Effets : grain, vignette, bandes ciné
- Galerie locale

Site 100 % statique, hébergé sur GitHub Pages.
