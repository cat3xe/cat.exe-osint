Plus de vidéos gratuites

Les vidéos sont calculées gratuitement sur les serveurs GPU de Hugging Face. Sans compte, chaque visiteur a un petit quota par jour. Avec un token Hugging Face gratuit (une clé personnelle), le quota augmente.

  1. Crée un compte gratuit sur huggingface.co
  2. Va dans Settings → Access Tokens → Create new token → type Read
  3. Colle-le ici :

Le token reste uniquement dans ton navigateur. Il est envoyé seulement à Hugging Face pour générer tes vidéos.
